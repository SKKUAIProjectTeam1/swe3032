# GNN 기반 자율 도로 설계 보고서 (V16)

## 1. 개요

성균관대 자과캠 건물 배치를 입력으로, 수업 데이터나 기존 도로 정보 없이 GNN이 기하학적으로 합리적인 도로망을 출력하도록 학습시킨 단일 캠퍼스 실험의 최종 버전.

## 2. V16 핵심 변경

이전 버전에서 반복된 '따개비(건물 밀착)' 및 도로 단절 문제를 해결하기 위해 아래 기법을 도입했다.

- **Ridge 보상 (Medial Axis):** Distance Transform으로 건물 사이 정중앙 지점을 계산, 도로가 건물 바로 옆이 아닌 건물 간 gap 중앙을 따라가도록 유도
- **Degree 정규화:** 각 노드의 연결 수를 2~3개로 제한하는 패널티 추가, 면 형태 대신 선형 도로 구조 유도
- **100×100 고해상도 격자:** 10,000 노드 / 80,000 엣지, 50,000 step 학습
- **게이트 위치 자동 도출:** 내부 도로 흐름에 따라 정문·후문 후보 위치를 기하학적으로 산출

## 3. 사양

- Framework: PyTorch
- 그래프: 100×100 격자 (10,000 노드)
- 학습: Adam, 50,000 step
- 제약: 건물 충돌 hard penalty, ridge 선호, 전역 연결성 메시지 패싱

## 4. 결과

- 출력 지도: `campus_v16_civil_design.png`
