# GNN 기반 캠퍼스 도로망 설계 보고서 (초기 실험)

초기 단일 캠퍼스 실험 단계(V1~V21) 결과 기록. 이후 멀티캠퍼스 일반화 방향으로 전환됨.

## 1. 실험 목표

기존 도로망 데이터나 유동 인구 정보 없이, 건물 배치(폴리곤)만 입력으로 받아 GNN이 합리적인 도로망을 스스로 출력할 수 있는지 확인한다.

## 2. 설계 원칙

- 이동 데이터 미사용: 수업 시간표나 유동 인구 데이터 없이 순수 기하학 정보만 활용
- 건물 충돌 방지: 건물을 폴리곤으로 정의해 도로가 건물을 관통하지 못하도록 hard constraint 적용
- 효율-비용 균형: 건물 간 이동 거리 최소화(연결성)와 도로 총 연장 최소화(경제성) 동시 고려

## 3. 구현

- 장애물 맵: `BUILDING_POLY` 기반으로 건물 내부를 통행 불가 구역으로 설정
- 경로 탐색: A* 알고리즘으로 건물을 우회하는 실제 보행 거리 계산 (건물 23개 전체 쌍)
- GNN: 건물 간 연결 가능성을 학습 파라미터로 설정, 허브 가중치 부여 (학생회관·도서관)
- 시각화: `campus_realistic_road_design.png`

## 4. 결과

- 추천 정문 방향: 북서쪽 — 기초학문·생명공학 구역 인접
- 추천 후문 방향: 남서쪽 — 수성관·의학관 구역 인접
- 직선으로 연결 불가한 건물 쌍에서 건물 사이 gap을 따라 우회 경로를 자동으로 생성함
- 허브(학생회관↔도서관) 축이 가장 높은 가중치로 형성됨

## 5. 한계 및 다음 단계

단일 캠퍼스(성균관대 자과캠)에만 맞춰 학습되어 다른 캠퍼스에 적용 불가. 이후 멀티캠퍼스 데이터셋(V22~)으로 방향 전환함.
